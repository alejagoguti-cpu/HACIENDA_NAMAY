# Hacienda Namay · Brand Book & Materiales

Sitio estático (GitHub Pages): identidad de marca, paleta, moodboards interactivos (Habitación, Baño, Recepción) renderizados desde `assets/moodboards.pdf` con PDF.js, y matriz de materiales con filtros y búsqueda.

- Contenido de la matriz y las láminas: arreglo `LAMINAS` / `MATERIALES` en `script.js`.
- Abrir `index.html` en el navegador (o con un servidor local para que cargue el PDF).
